End-to-End GCP Medallion Pipeline Architecture
Designed following enterprise production data engineering best practices.

📥 1. Ingestion (Bronze)

  • OpenF1 REST API (7 endpoints)
  • Token bucket rate-limiter (30 RPM)
  • Exponential back-off retry logic
  • Raw JSON partitioned on GCS

⚡ 2. PySpark (Silver)

  • Schema enforcement & UTC timestamps
  • Deduplication on session/lap keys
  • Calculated tyre_life & lap durations
  • Snappy-compressed Parquet on GCS

📊 3. Analytics (Gold)

  • PySpark strategy aggregations
  • Partitioned & Clustered BigQuery tables
  • Tyre degradation delta curves
  • Loaded directly via GCS to BQ API

🌐 4. Presentation

  • Cloud BI: Looker Studio BigQuery connector
  • Deployable Web UI (Zero dependency)
  • Interactive Chart.js visualizations
  • Free hosting via GitHub Pages
